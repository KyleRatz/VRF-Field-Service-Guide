Sensor replacement / binding — safe workflow

1
Identify the exact sensor

Record controller name, sensor label, circuit, connector, part number and current displayed value before disconnecting anything.

2
Verify the failure

Compare the displayed value with a trusted thermometer, pressure gauge or resistance/voltage specification. Check wiring and connector condition first.

3
Replace only with the correct type

Thermistors, RTDs and pressure transducers are not interchangeable just because the connector fits.

4
Bind / configure from the exact controller procedure

Some controllers auto-discover sensors; others require an address, input assignment, offset, calibration or service password. The app will store exact model-specific steps as manuals are added.

5
Prove the repair

Confirm the controller value matches the independent instrument and verify the associated safety/alarm clears normally.

Field safety

Follow the manufacturer IOM/service manual and site LOTO procedures. Never bypass a safety to keep a chiller running. Do not enter service-level controller menus or change calibration/binding values unless the exact machine procedure is confirmed.
